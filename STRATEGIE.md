## 1. Modèle de Revenus — 3 options non-intrusives

### Option A : PDF Premium (recommandé)
- **Fonctionnement :** Calcul gratuit en ligne → option « Télécharger mon analyse complète » (PDF 5-10 pages) → 3-5 €
- **Avantage :** L'utilisateur a déjà vu la valeur (résultat gratuit), le PDF est un upgrade naturel
- **Modèle :** Co-Star, The Pattern
- **Priorité :** P2 (après validation du trafic)

### Option B : Donations
- **Fonctionnement :** Page "Soutenir" avec Buy Me a Coffee, Liberapay, ou Stripe Payment Link
- **Avantage :** Zéro friction, aligné avec l'éthique du projet
- **Inconvénient :** Revenus très faibles (< 50 €/mois en moyenne)
- **Priorité :** P2 (faible effort, activable immédiatement)

### Option C : Newsletter monétisable
- **Fonctionnement :** Formulaire newsletter gratuit → liste d'audience → futur ebook/formation payante
- **Avantage :** Construit une audience propriétaire
- **Inconvénient :** Nécessite du contenu régulier
- **Priorité :** P3 (nécessite une audience d'abord)

## 3. Stratégie de Rétention

### Problème : usage unique
La numérologie se calcule une fois. L'utilisateur n'a pas de raison de revenir.

### Solutions

| Solution | Détail | Priorité |
|----------|--------|----------|
| **Année personnelle** | Calcul qui change chaque année → l'utilisateur revient le 1er janvier | P2 |
| **Numéroscope mensuel** | "L'énergie de ton mois" selon le jour | P3 |
| **Blog** | Articles réguliers → abonnement RSS/newsletter | P1 |
| **Tirage du jour** | Un chiffre/archétype aléatoire chaque jour → habitude | P2 |
| **Comparaison couple** | "Et avec ton/ta partenaire ?" → deuxième usage | P1 |

## 5. Critères d'Arrêt (Fail Fast)

> *Quand ce projet est-il un échec ?*

- ❌ **< 50 visiteurs uniques/jour après 3 mois** → le concept n'accroche pas
- ❌ **0 partage organique après 1 mois** → pas de viralité
- ❌ **Coût d'hébergement > 20 €/mois sans revenus après 6 mois** → non viable

**Si 2 critères sur 3 sont atteints → pivot ou arrêt. Sinon → continuer.**
